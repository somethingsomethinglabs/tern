# Trailrest

Trailrest is a browser organized around unfinished work. Users put a task aside with a short note and resume its pages when ready. Task lifecycle and website save state are separate facts.

## Glossary

- **Task**: A named piece of work with pages and a resumption note.
- **Active**: Work currently in progress.
- **Later**: Work explicitly put aside to resume.
- **Settled**: Work the user has explicitly marked finished. This does not certify website submission.
- **Page**: A website belonging to a task.
- **Live page**: A running page instance whose in-memory state is still available.
- **Reference**: A saved page address that must be reopened. It does not contain unsaved form state.
- **Resumption note**: The user's description of where they left off and what to do next.
